# Support Agent

## Daily work

Support Agents answer customer messages in the Inbox, look up orders, and add internal notes. They see the customer's order history but never the full card number.

## Refund requests

A Support Agent opens a refund request from the order page and picks a reason: damaged item, late delivery, wrong item, or goodwill. Goodwill refunds need a note of at least one sentence. The request then waits for a Reviewer.

## What Support Agents cannot do

Support Agents cannot approve refunds, publish products, or invite staff. They can read the catalog but not edit drafts.
