# Two-factor authentication

## Required for every account

Every Back Office account must use two-factor authentication. Owners and Admins must use a hardware security key; other roles may use an authenticator app instead.

## Recovery codes

Each account gets ten single-use recovery codes when two-factor authentication is turned on. A used code cannot be used again; generate a new set from the Security page when fewer than three are left.

## Lost devices

If someone loses their key or phone and has no recovery code left, an Owner resets their two-factor setup. The reset is written to the audit log and the person must set up a new factor at the next sign-in.
